# 김도현

_updated at 2026-07_

4년간 B2B 제품과 사내 운영 도구를 개발해 온 프론트엔드 엔지니어입니다.

신규 모빌리티 플랫폼의 프론트엔드 기반을 설계하고, 여러 서비스가 함께 사용하는 디자인 시스템과 API 타입 자동화를 구축했습니다.

제품 UX와 개발 생산성의 병목을 구조로 풀어내며, 필요한 문제라면 AI 기반 운영 도구와 Native Bridge처럼 프론트엔드 경계 밖까지 파고듭니다.

#### B2B 모빌리티 플랫폼 신규 구축 및 확장

**2024년 10월 ~ 2025년 05월 구축·출시 / 이후 유지보수 및 기능 확장**

- 차량 자산을 기반으로 한 B2B Web·Admin·WebView를 0부터 구축해 2025년 05월 출시했습니다.
- 차량 관제 지도에서 수천 대 마커가 몰려도 조작 가능한 성능을 확보했습니다.
  - Chrome DevTools FPS Meter와 4x throttling 환경에서 프레임 드롭/프리징을 재현하고, 기획자와 필요한 마커 밀도를 협의
  - 클러스터링, 이동 중 마커 렌더 debounce, 이미지 기반 마커를 조합해 고밀도 지역에서도 **60fps 수준 유지**
- 앱에서 차량 제어를 위한 BLE bridge 호출, Timeout 시 Web API fallback 호출 구조를 구축하였습니다.
- Next.js 앱의 로그 수집 방법을 표준화하고, Server Action 기반 logger와 Slack 알림 전송, AWS Logs Insights 조회 흐름을 구축했습니다.
  - Client Runtime Error, API 호출 lifecycle, Server Error를 각 Runtime의 진입점에서 수집
  - [Next.js에서 자동화된 로깅 구조 만들기](/blog/nextjs-logging-strategy)
- 백엔드 파트에서 구축한 OpenAPI 제공을 위한 [개발자센터](https://developers.carplat.co.kr) 사이트를 구축하였습니다.
  - OpenAPI YAML 을 파싱하여 표시하는 구조
